# 0.4.8 — installation decision points and numeric examples

This source update follows review of the 0.4.7 retest. The published `v0.4.5` tag and curated release assets remain unchanged.

- The agent recipe and starting prompt require genuine filesystem tools, unchanged path components and a supplied exact record before any record selection. Manual fallback is for the user to perform; the agent must not offer its own replacement copy procedure.
- An explicit permission denial stops the affected operation, including verification. Different flags, scripts, interpreters or shell commands are not authorization to retry. Missing software and denied permission are distinct outcomes.
- Guidance excludes installation through symlinks, checks conflicts before manual copying and preserves later custom changes during manual-removal review.
- Dyscalculia keeps unrequested teaching examples out of Working. Requested teaching examples use a separate labelled table, and conversion-factor columns name compound units. Numeric tables retain a separate final explanation column.
- The deterministic helper retains its existing source/ownership records, fail-closed checks and recoverable quarantine. Its source identity remains a caller assertion, not download authentication.

The reviewed 0.4.7 sample passed 65 of 66 fixed behavior turns. Agent results are 28 of 33 after correcting a missed denial-retry failure. Those results remain historical evidence, not proof that the new instructions will always be followed. Restricted-capability tests still showed a premature access announcement; this remains unresolved. Genuine tool-less behavior needs a new host test and remains unqualified. See the README for checks actually performed on this revision and remaining limits.

# 0.4.7 — recorded installation and recoverable removal

This source update follows independent review of the 0.4.6 return. It does not replace the published `v0.4.5` tag or curated release assets.

- `scripts/install_pack.py` provides read-only installation/removal previews and explicit `--apply` operations for copied Codex/Hermes skills. Python 3.10+ is required for this route; manual copying and the browser picker remain available without it.
- Every applied install has a durable self-contained ownership record, including a no-op run that owns nothing. Removal requires its exact record and unchanged complete trees, then moves only owned skills into retained quarantine. It does not permanently delete them or reconstruct missing records.
- Missing/edited/extra/link entries, malformed records, incomplete transactions, conflicting skills and ambiguous case/Unicode path aliases stop operations. Stop other writers during installation/removal; this is not a security boundary against malicious local processes.
- Numeric examples keep duration, ratio and clock roles in correctly labelled columns. Overviews check actual members. Planning preserves risk and authorization without adding a hold request. Communication retains every supplied fragment. Pause points use observable state.
- Alexithymia deactivation separates the acknowledgement from any accompanying answer and its requested sentence count.
- Generated area skills clarify that optional supports remain off until enabled. Default draft greetings are not prohibited by an inactive optional setting.
- Installation instructions use the supplied helper, preserve records and distinguish copied skills from Claude's own plugin install/update/uninstall routes.

The preceding Claude return contained real unsafe agent removal and eight confirmed output-contract failures. Replacing the removal mechanism is a stronger boundary than another prose-only recipe, but an agent can still ignore instructions; the next Claude retest must verify helper use and refusals in real sessions. The helper's quarantine is retained recovery data, not an automatic rollback or backup service. Legacy/manual installations require separate ownership review.

See [README validation status](README.md#validation-status) for fresh checks and remaining gates. Native Windows, Cowork, Hermes and screen-reader execution remain unqualified. Browser manual selection may omit a final newline; Download preserves exact export bytes. The private Claude mod is not included in this source update.

# 0.4.5 — first early-access bundle (historical publication record)

A downloadable needs picker and optional skills for choosing how an assistant presents information. Start with [START_HERE.md](START_HERE.md), or give [INSTALL_WITH_AGENT.md](INSTALL_WITH_AGENT.md) to a local coding agent when asking it to help install.

This release packages the tested 0.4.5 skill content from commit `11b3a2c9ec793623887e324822854871eb8d1358`. Added onboarding documents do not change skill behavior or plugin versions. The final packaging commit is recorded in the curated ZIP's `BUNDLE_MANIFEST.json` and GitHub's `v0.4.5` release tag.

## Included

- Standalone browser picker: 89 supports across 12 areas; no build or Python needed.
- 19 authored skills and 12 area skills, with 31 complete skills in each generated platform tree.
- Separate Claude marketplace route containing 19 authored skills.
- Start guide, installation/removal guide, agent-install recipe, licence and upstream attribution.
- Source and existing checks for reproducibility. Private research, review transcripts, accounts, machine configuration and Git history are not packaged.

## Repairs already in 0.4.5

Planning removes discarded instructions and unrequested greetings while preserving supplied wording. Numeric rules check unused calculation fragments and misleading glosses.
